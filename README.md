# OpenList Companion

OpenList Companion provides injection snippets for adding a TMDB manual metadata matcher to OpenList directory pages.

## Files

- `head.html`: Style snippet for the OpenList `customize_head` / custom head field.
- `body.html`: JavaScript snippet for the OpenList `customize_body` / custom body field.

## Usage

Open the OpenList admin settings page, paste `head.html` into the custom head field, and paste `body.html` into the custom body field. After saving, return to a normal directory page and use the TMDB button in the bottom-right toolbar.
